# Laboratory 03 – Multi-Cloud Explorer

## Mission 3: Become a Multi-Cloud Explorer

This laboratory compares Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). The goal is to understand their services and choose a cloud platform based on business requirements.

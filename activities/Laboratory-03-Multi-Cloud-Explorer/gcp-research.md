# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is a public cloud platform that provides infrastructure, storage, databases, networking, analytics, artificial intelligence, and container services.

## Global Infrastructure

Google Cloud currently lists 43 global regions and 130 zones. Its infrastructure is designed to provide global scale, performance, and resilience. Google Cloud also provides a large global network and edge infrastructure for applications that need low latency.

## Cloud Management Console

The **Google Cloud Console** is a web-based interface used to create, configure, monitor, and manage Google Cloud resources. It can be used for services such as Compute Engine, Cloud Storage, VPC, Cloud SQL, and Google Kubernetes Engine.

## Four Core Services

1. **Compute Engine** – provides virtual machines for cloud workloads.
2. **Cloud Storage** – provides object storage.
3. **Virtual Private Cloud (VPC)** – provides networking for cloud resources.
4. **Identity and Access Management (IAM)** – manages access to Google Cloud resources.

## Three Advantages

1. Strong artificial intelligence and machine learning capabilities.
2. Strong Kubernetes and container technology through Google Kubernetes Engine.
3. Global infrastructure designed for scalable and high-performance workloads.

## Typical Enterprise Use Cases

- AI and machine learning
- Kubernetes and containerized applications
- Big data analytics
- Web and mobile applications
- Global services
- Data storage and processing

# Activity 2 part 2 – Welcome to the Cloud

## Mission Overview

The mission of this laboratory was to get familiar with a Linux environment and basic cloud computing tools. I used KillerCoda to launch an Ubuntu playground and practiced working with the Linux terminal.

## Objectives

* Launch and explore an Ubuntu Linux environment.
* Create and manage a Linux user account.
* Check basic system information.
* Create and organize folders and files.
* Create a GitHub repository for my Cloud Computing portfolio.
* Practice basic Linux commands.

## Activities Performed

1. Launched Ubuntu using KillerCoda.
2. Checked the Linux terminal and verified that it was working.
3. Created a new user with a home directory, Bash shell, and sudo access.
4. Logged in to the new user account.
5. Checked the Linux distribution, kernel version, CPU, memory, and disk space.
6. Created the `Notes`, `Reports`, and `Screenshots` folders.
7. Created the `about-me.md` file inside the `Notes` folder.
8. Created a public GitHub repository for my Cloud Computing activities.
9. Organized the laboratory files and screenshots in the repository.

## Skills Learned

Through this laboratory, I learned how to use basic Linux commands and navigate the terminal. I also learned how to create users, folders, and Markdown files. I became more familiar with checking system information and organizing files in a Linux environment. I also learned how GitHub can be used to store and organize my Cloud Computing laboratory activities.
